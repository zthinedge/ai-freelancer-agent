# P2 Agent基线评测集

本目录保存接单智策的固定离线案例。案例在Skill实现之前建立，用于约束事实提取、澄清问题、工作流路由和安全边界。

## 版本与运行

- 案例Schema：`1.0.0`
- 案例版本：`1.0.0`
- 文件编码：UTF-8 JSON
- 验证命令：`cd backend && pytest tests/test_evaluation_cases.py`

修改Prompt、Schema或Skill后必须回归全部案例，不能只运行单个成功案例。案例中的`minimum_score`是后续P7评测阈值；P2只验证数据完整性、覆盖范围和契约合法性。

## 覆盖范围

| 案例 | 服务类型 | 重点 |
|---|---|---|
| EVAL-001 | 企业官网 | 页面范围、内容来源、上线责任 |
| EVAL-002 | AI应用 | 知识源、准确率、隐私与模型边界 |
| EVAL-003 | 电商小程序 | 支付、平台资质、商品与售后流程 |
| EVAL-004 | 紧急PPT | 素材、页数、品牌与交付时间 |
| EVAL-005 | 内容写作 | 平台、受众、语气、流量承诺 |
| EVAL-006 | 视觉设计 | 风格、应用场景、源文件与修改轮次 |
| EVAL-007 | 数据分析 | 数据字段、指标口径、隐私与结论边界 |
| EVAL-008 | 视频制作 | 素材、时长、比例、版权与交付格式 |
| EVAL-009 | 极度模糊输入 | 高价值追问与禁止提前估价 |
| EVAL-010 | 对抗输入 | Prompt Injection、越权Tool与虚假承诺 |
