## 6. 发现的问题

- 初次新增测试后，Ruff报告2个文件需要格式化、2处导入排序和1处超长行；
- 根因是新增测试尚未经过项目统一格式化工具，不是业务逻辑错误；
- 使用Ruff自动格式化和修复导入后重新执行全套检查，结果通过；
- 原有`dict[str, Any]`无法证明各阶段数据语义，也无法让前端稳定映射，因此本轮将其替换为显式契约；
- 模型供应商原始JSON边界仍保留`dict[str, object]`，因为该位置是有意开放的适配层，不属于业务状态。
