# 功能拆解与开发计划

> 详细执行进度见[开发流程与项目进度表](06-开发流程与项目进度表.md)，模块边界与依赖规则见[系统架构设计](07-系统架构设计.md)。

## 1. 模块拆解

| 模块 | 子功能 | 依赖 | 交付物 | 验收方式 |
|---|---|---|---|---|
| 项目录入 | 名称、客户原话、类型、预算、期限、时薪 | 无 | React表单、请求模型 | 合法输入可提交，非法输入提示 |
| AI分析 | 分类、信息提取、追问、范围、风险 | 项目录入 | 分析服务、结构化Schema | 真实AI或规则回退均返回同一结构 |
| 工时报价 | 任务拆分、总工时、三级报价、预算提醒 | AI分析 | 报价计算器 | 金额可由工时和时薪复算 |
| 项目存储 | 新建、列表、详情、删除 | 分析结果 | SQLite表、REST API | 重启后记录不丢失 |
| 结果工作台 | 范围卡片、任务、价格、风险和验收 | 全部后端 | 响应式页面 | 桌面和375px均可操作 |

## 2. 技术架构

```text
React: app -> pages -> features -> entities -> shared
                         | JSON / REST
FastAPI: presentation -> application / agent -> domain
                         ^
             infrastructure adapters
```

项目采用模块化单体。模型、SQLite、Trace和报价Tool均通过端口接入，具体实现只在Composition Root装配。

## 3. 五日开发计划

| 日期 | 主要任务 | AI协作重点 | 验收标准 |
|---|---|---|---|
| 第1日 | 用户分析、PRD、数据模型、API契约 | 需求检查、边界审查 | PRD和接口结构定稿 |
| 第2日 | FastAPI、SQLite、规则分析与报价 | 生成骨架、补充异常处理 | API可完成分析和保存 |
| 第3日 | React表单、项目列表、结果页面 | 生成组件、联调排错 | 浏览器跑通核心闭环 |
| 第4日 | 测试、空态、错误态、移动端和真实AI | 生成测试、Bug根因分析 | ≥10用例、构建通过 |
| 第5日 | 用户测试、部署、README、截图和复盘 | 整理文档、生成演示脚本 | 公网链接和完整材料 |

## 4. Prompt策略

开发协作Prompt、运行时Skill Prompt和作业证据记录统一使用[Prompt工程模板与作业记录规范](08-Prompt工程模板与作业记录规范.md)。

### 系统角色

你是一名兼具产品经理、项目经理和自由职业商务顾问能力的需求分析师。你的职责是发现需求缺口、控制项目范围并给出可解释的任务建议；不得承诺结果，不得把不确定信息写成事实。

### 输出约束

- 只输出JSON；
- 严格符合服务端Schema；
- 已明确的信息不得重复追问；
- Must只保留完成核心闭环所必需的功能；
- 工时以0.5小时为最小单位；
- 报价金额由服务端计算，模型只输出任务工时和风险。

### 迭代记录模板

| 轮次 | 目标 | Prompt变化 | 输出问题 | 修正结果 |
|---|---|---|---|---|
| V1 | 生成需求清单 | 初始角色+JSON | 问题过于通用 | 待记录 |
| V2 | 提高项目相关性 | 增加服务类型与已知信息 | 待记录 | 待记录 |
| V3 | 控制范围 | 增加MoSCoW和排除项规则 | 待记录 | 待记录 |

## 5. 测试计划

### 后端自动化测试

- 健康检查；
- 创建开发类项目；
- 创建内容类项目；
- 输入过短返回422；
- 负数预算返回422；
- 项目列表；
- 项目详情；
- 不存在项目返回404；
- 删除项目；
- 无效AI响应时自动降级；
- 报价随时薪变化；
- 预算不足提醒。

### 用户测试

邀请3名用户分别使用同一段模糊需求：

> 我想做一个AI网站，能上传资料然后问问题，最好这周做好，预算不高。

记录完成耗时、追问是否有用、范围是否合理、报价是否可信以及最希望修改的地方。

## 6. Definition of Done

- 核心流程可从浏览器完整运行；
- 无密钥环境也能稳定演示；
- API文档可访问；
- 后端测试和前端构建通过；
- README可让新用户在10分钟内启动；
- 至少保留3次有意义的Prompt／Bug迭代证据；
- 关键页面具备加载、空态和错误反馈。
